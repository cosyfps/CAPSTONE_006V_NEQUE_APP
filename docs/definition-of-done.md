# Definition of Done

Para considerar una historia de usuario o funcionalidad como terminada dentro del proyecto Ñeque, debe cumplir con los siguientes criterios:

- La funcionalidad solicitada se encuentra implementada.
- Cumple con el objetivo definido en la historia de usuario.
- Puede ser utilizada sin errores críticos conocidos.
- La funcionalidad fue probada por al menos un integrante del equipo.
- Los cambios se encuentran registrados en el repositorio mediante control de versiones.
- La funcionalidad no afecta negativamente otras partes del sistema.
- En caso de ser necesario, la documentación técnica correspondiente fue actualizada.
- La funcionalidad se encuentra en condiciones de ser presentada o demostrada.

Estos criterios permiten establecer una definición común de cuándo una tarea puede considerarse realmente finalizada.
